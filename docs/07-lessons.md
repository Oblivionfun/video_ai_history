# 07 · 踩坑记录

每一条都是真实发生过、花时间排查过的问题。改相关代码前先看一眼。

## 渲染与 Remotion

| 现象 | 原因 | 对策 |
|---|---|---|
| 地图画布只有 1920×300 | 挂载时容器高度为 0，MapLibre 用了默认 300px | 地图容器必须绝对定位并给定宽高；`load` 后调用 `map.resize()`（已在 `MapScene` 里） |
| 偶发空白帧 | 初始化的 `delayRender` 句柄先于逐帧句柄释放 | 逐帧 effect 先注册自己的句柄，再释放初始化句柄（已修好，别改顺序） |
| 静帧里路线消失 | `<Freeze>` 会把帧号钳制在合成时长内，1 帧的封面合成被钳到第 0 帧 | 静帧/封面不要用 `Freeze`，给 `MapScene` 传 `time` 属性 |
| 静帧里 `NaN` 坐标报错 | 两个镜头关键帧落在同一时刻（短语正好在句首），样条除以零 | `makeCamera` 已自动把重复时刻错开 0.05 秒；写 JSON 时尽量别把两个 key 锚到同一点 |
| 竖版里粒子被拉伸 | `FrameCanvas` 写死 1920×1080 | 已改为读取合成尺寸；新特效一律用 `useVideoConfig()` 的宽高 |
| 渲染中途改代码，后面的合成用了新代码 | 每次 `npx remotion render` 都重新打包 | 批量渲染用 `video/scripts/render.mjs`（只打包一次）；渲染进行中不要动 `video/src` |
| 渲染速度只有平时一半 | 机器上其他程序（浏览器、聊天软件）占满 CPU | 渲染前关掉重负载程序；`--concurrency` 不要超过 6 |

## 地图

| 现象 | 原因 | 对策 |
|---|---|---|
| 近景发糊、发灰 | Blue Marble 最高只到 z8（约 500 米/像素），zoom 8.5 以上是放大插值；高俯仰角时远处雾化严重 | 近景控制在 zoom ≤ 8.4、pitch ≤ 60；冷开场叠了 `contrast/saturate` 滤镜。真要更清晰，需要可商用的高分辨率影像（见 `docs/05`） |
| 竖排地名“长安”显示成“安长” | `writing-mode: vertical-rl` 没禁止换行 | 竖排文字必须加 `white-space: nowrap` |
| 标签互相遮挡（“女儿国”被“火焰山”完全盖住） | 两地相距不到 0.5°，标签同向 | 拥挤处用 `epiSide` / `side` / `dy` 调整；每次改动后看全景静帧 |
| 竖版里右侧标签出画 | 竖版画面窄，`side: 'r'` 的长标签越界 | 竖版靠右的点改 `side: 'l'` |
| 路线在低 zoom 不显示（曾怀疑） | 实际原因是 Freeze 钳帧，不是投影 | 短片一律用 `mercator` 投影，避免地球投影过渡区的不确定性 |

## 文本与字幕

| 现象 | 原因 | 对策 |
|---|---|---|
| 字幕吃掉右引号 | 按标点切分的正则没处理“。”后紧跟的” | `timeline.py` 用负向前瞻 `(?!”)` |
| 新文字显示成系统字体 | 字体按字符子集加载，新文字不在 `ALL_TEXT` 里 | 新 UI 文案加进 `text.ts`；cut JSON 的文字已自动收集 |
| 片尾标题折行压到下一行 | 书法字宽度估算不准 | 长标题加 `white-space: nowrap` 并留余量 |
| 重渲旧一期时片尾“下期预告”变成了最新一期的预告 | 预告写在全频道共用的 `brand.json` | 已移到每期 `episode.json` 的 `next`；`brand.json` 只放频道名、口号、更新频率 |

## 配音

| 现象 | 原因 | 对策 |
|---|---|---|
| 多音字/生僻字读错（莫贺延碛、可汗、麴文泰、大乘） | 免费 edge-tts 不能用 SSML/拼音标注 | 统一写进 `config/pronunciations.json`；edge 用等长同音字替换，其他提供方自动编译成拼音标注 |
| 改了一个字，整片时间轴错位 | 时间轴由配音时长决定 | 正常现象：改稿后跑 `voice → timeline`，所有画面锚点会自动跟着移动；只是不要手写绝对秒数 |
| edge-tts 偶发失败 | 免费接口网络抖动 | `tts.py` 自带 5 次重试；有缓存，重跑只合成改动过的句子 |
| 换成豆包后整片慢了 25–40%，逗号后停 1 秒多 | 豆包句内停顿长；语气提示里写“语速稍慢”又叠加了 `speech_rate` -8 | 语气提示别写语速；用 `max_pause` 压缩停顿（见 `docs/04`）；短片 `speech_rate` 6 |
| 豆包音频开头留了 0.45 秒空白 | 开头一个很轻的噪声被当成了开口 | `trim` 只认连续 40 毫秒以上的声音为开口 |

## 音频

| 现象 | 原因 | 对策 |
|---|---|---|
| 低频发闷 | 合成垫音在 200 Hz 以下堆积 | 38 Hz 高通 + 180 Hz 以下约 -6 dB（`tame_low`） |
| 解说被音乐盖住（人声只比背景高 7 LU） | 包络式闪避太浅且在字间抽吸 | 现方案：整句闪避 + 音效瞬时压制 + 逐句自动推子 + 段间音乐限幅；验收标准见 `docs/04` |
| 混音是 −1.2 dBTP，成片质检却是 −1.0 到 −1.1 | AAC 编码抬高真峰值 0.1–0.4 dB；豆包齿音、雷声浪声的高频瞬态最明显 | 限幅上限设 −1.8 dBTP（`score.py` 的 `TP_CEILING`），以成片质检为准 |
| 配乐合成从 90 秒拖到 25 分钟 | 机器同时跑别的渲染 | 合成结果缓存为分轨（`stem_*.npy`），只调混音用 `--remix`（约 20 秒） |

## 流程

| 教训 | 做法 |
|---|---|
| 质检太晚才发现混音问题 | 每次出片都跑 `studio.py qa`，看响度、可懂度报告和联系表 |
| 开头 3 秒黑场、18 秒才出标题 | 所有片子前 5 秒必须给钩子（问题 + 最强画面） |
| 只做了横版 | 每期默认产出横版长片 + 竖版短片 + 竖版中长片 |
| 机器上并行跑太多任务 | 渲染、配乐合成这类重任务串行执行 |
| 渲染开始后才改的 JSON 没进成片（ep01 的 s1 标签方向、s3 封面时刻） | 改动时记下受影响的合成，等这批渲染结束后只重渲这几条；`ps -o lstart` 可以看渲染进程何时启动（即打包时刻） |
| 重构引擎时怕改坏已发布的一期 | 新旧实现做数值对比（例：`makeJourney` 重构时逐项比对路径、节点、分段完全相等），再对同一时刻出静帧对比 |
