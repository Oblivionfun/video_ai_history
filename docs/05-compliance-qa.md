# 05 · 合规红线与发布前质检

## 红线（踩到可能下架、罚款或封号）

1. **地图**
   - 不画任何现代国界、省界，不用色块填充疆域；只用地形、路线、古地名。
   - 镜头不要拉到能被理解为“中国全图”的范围；航线经过南海、东海时只跟随航线和港口，不标岛礁名称。
   - 必须出现中国全图时，只能原样使用自然资源部标准地图服务（bzdt.ch.mnr.gov.cn）的地图并标注审图号；缩放修改后要重新送审。
   - 画历史疆域属于“历史地图”，需要送自然资源部审核——本频道默认不画疆域。
2. **广电“AI 魔改”专项（2026-01 起常态化）**：不使用任何影视剧画面、演员形象；不颠覆名著人物与情节；不歪曲历史时空。我们的做法是原创插画 + 考据式解读。
3. **AI 标识**：《人工智能生成合成内容标识办法》2025-09-01 起施行。所有国内平台发布时打开“含 AI 生成内容”声明；豆包等接口支持写入 AIGC 元数据（`aigc_metadata`），可以开启。
4. **版权**
   - 不用 86 版《西游记》等剧照、截图。
   - 字体只用开源（OFL）或已购商用授权的字体。现用：Noto Serif SC、Ma Shan Zheng、Zhi Mang Xing、Cormorant Garamond，均为 OFL。
   - 音乐：现用程序化原创配乐。换成曲库或 AI 音乐时，保留授权凭证；海绵音乐等“仅个人非营利”的不能用；Suno 条款提示第三方平台可能被认领。
   - 底图：NASA Blue Marble、Natural Earth 为公有领域，Tilezen 地形需署名。EOX Sentinel-2 cloudless 2018 年后的版本禁止商用，不要用于变现视频。
5. **平台规则**：B站激励要求首发；YouTube 不变现“模板化量产”内容（inauthentic content），每期叙事和画面要有差异；微信有“非真人自动化创作行为”条款，账号要真人运营、真人回复评论。
6. **声音**：只克隆自己的声音，克隆他人声音需本人单独书面同意；保留原始录音和授权记录。
7. **史实**：民族、宗教、边疆、革命题材慎选；每句可追溯一手史料；学界说法要写“有学者认为”“一说”。

## 发布前质检（每个成片都过一遍）

自动（`python scripts/studio.py qa <ep>`）：
- [ ] 响度：长片 -15 ±1 LUFS，短片 -14.5 ±1 LUFS；真峰值 ≤ -1.0 dBTP
- [ ] 无孤立闪帧（报告里的候选逐个看：闪电、硬切是正常的）
- [ ] 闪电等大面积闪光：任意 1 秒内不超过 3 次明暗往返（ITU-R BT.1702 光敏癫痫标准）。量法：`ffmpeg -ss <秒> -t 5 -i 成片.mp4 -vf scale=192:108,format=gray -f rawvideo -` 逐帧算平均亮度，数峰值。ep01 的雷暴段每次落雷是“双闪”约 0.27 秒、间隔 1.3 秒，每秒最多 2 次
- [ ] 无意外黑场（只允许开头淡入、结尾淡出）
- [ ] 联系表 20 帧逐张看：标签不出画、不互相遮挡，卡片不压字幕

混音日志（`score.py` 输出）：
- [ ] 每句解说比背景至少高 14 LU（看 `voice over bed per line` 的 min）
- [ ] 1–4 kHz 语音频段被遮挡比例 < 2%

人工：
- [ ] 前 5 秒有钩子；结尾有下期预告和关注引导
- [ ] 读音：通听一遍，重点听人名地名（发音词典之外的生僻字补进 `config/pronunciations.json`）
- [ ] 史实：脚本每句有出处；“原型说”标明是学界观点
- [ ] 地图：没有国界、没有疆域色块、没有中国全图式画面
- [ ] 封面：缩到 400 像素宽标题仍清楚
- [ ] 发布文案：简介写明史料、AI 说明；平台 AI 声明已勾选
