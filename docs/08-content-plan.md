## ep02 · 李白一生，到底走了多远？（10/16）

- **钩子**：他写尽了天下山水——一生到底走了多远？竖版：“李白的出生地，玄奘曾经路过”（碎叶城，与 ep01 联动）。
- **主线**：出生（碎叶说 / 蜀中说，两说并列，待核）→ 蜀中少年（江油、峨眉）→ 725 年“仗剑去国，辞亲远游”出蜀 → 江陵、洞庭、金陵、扬州 → 安陆十年 → 742 年待诏翰林“仰天大笑出门去”→ 744 年与杜甫相遇（洛阳、梁宋，待核）→ 齐鲁、江南漫游 → 安史之乱、入永王幕 → 流放夜郎，759 年白帝城遇赦“朝辞白帝彩云间”→ 762 年卒于当涂。
- **地图**：碎叶 → 四川 → 长江中下游 → 长安 → 山东 → 江南 → 夜郎方向（中途折返）→ 当涂。现有瓦片已覆盖全程；河流要补长江、汉水、淮河（`scripts/extract_rivers.py`）。
- **史实 × 文学**：每一站配一句李白自己的诗作为“戏”卡（诗句即一手材料）；路线长度用地图实测（地图上量出的近似值要注明“按路线估算”）。
- **竖版切片**：① 李白的出生地，玄奘曾路过 ② “朝辞白帝彩云间”，一天真能到江陵吗？（《荆州记》“朝发白帝，暮到江陵，其间千二百里”）③ 李白和杜甫一生见过几次？ ④ 李白真是捞月亮淹死的吗？（传说与正史对照，待核）⑤ 李白为什么一辈子没考科举？（待核）
- **文旅**：江油、马鞍山（当涂、采石矶）、宣城（敬亭山）、安陆、奉节（白帝城）、扬州。
- **史料**：《李太白全集》、李阳冰《草堂集序》、范传正《唐左拾遗翰林学士李公新墓碑》、詹锳《李白诗文系年》。
- **合规**：碎叶城在今吉尔吉斯斯坦境内，只画地形和古地名，不画国界。

## ep03 · 哪吒、姜子牙真的存在吗？封神之战的真实地图（10/23）

- **钩子**：封神榜里的大战，真实战场在哪？
- **主线**：周原、丰镐 → 孟津观兵 → 牧野之战（约前 1046 年）→ 朝歌。硬证据：利簋铭文“武王征商，唯甲子朝”（1976 年临潼出土，待核出土细节）。姜子牙（吕尚）是真实人物；哪吒形象源自佛教护法“那吒”，可追溯到印度神话（与 ep01 的印度段联动，待核源流）。
- **地图**：关中 → 豫北，小范围；加一条“那吒”从印度经西域传入中国的示意弧线。
- **竖版切片**：① 哪吒其实来自印度？ ② 牧野之战，只打了一个早上？ ③ 姜子牙钓鱼的地方在哪？（渭水磻溪，待核） ④ 商朝的都城到底在哪：朝歌还是殷墟？（待核）⑤ 史书里的妲己是什么样？（《史记·殷本纪》对照《封神演义》）
- **文旅**：宝鸡（周原、磻溪）、淇县（朝歌）、孟津、新乡（牧野）。
- **史料**：《史记·周本纪》《尚书·牧誓》、利簋铭文、《封神演义》。
- **合规**：不使用任何影视剧画面；神话人物用原创插画，考据式讲解，避免“魔改”。

## ep04 · 问汝平生功业：苏轼被贬了多远？（10/30）

- **钩子**：一生被贬三次，最远到了海南——苏轼一共走了多远？
- **主线**：眉山 → 1057 年进士 → 凤翔、杭州、密州、徐州、湖州 → 1079 年乌台诗案 → 黄州（《赤壁赋》）→ 回朝、再知杭州（苏堤）→ 1094 年惠州 → 1097 年儋州 → 北归，1101 年卒于常州。《自题金山画像》：“问汝平生功业，黄州惠州儋州。”
- **地图**：四川 → 中原 → 江南 → 岭南 → 海南（新增岭南、海南瓦片）。
- **竖版切片**：① 苏轼游的赤壁，根本不是三国那个赤壁（东坡赤壁 vs 赤壁市，为 ep08 预热）② “日啖荔枝三百颗”，苏轼在惠州 ③ 从惠州到儋州，路上走了多久？ ④ 乌台诗案：几首诗差点要了苏轼的命 ⑤ 苏轼一生被贬到过哪些地方？（地图统计）
- **文旅**：眉山、黄冈、惠州、儋州、杭州、常州——多城市，最适合做文旅合作样片。
- **史料**：《宋史·苏轼传》、孔凡礼《苏轼年谱》、苏轼诗文。

## ep11 · 一骑红尘妃子笑：荔枝怎么运到长安？（12/18）

- **钩子**：荔枝三天就变味，唐朝人怎么送到长安？
