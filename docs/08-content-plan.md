# 08 · 未来 10 期选题与发布日历

> 定位：**用一张会动的地图，讲透一个故事的真实地理**。四条内容线：名著×真实地理（旗舰）、古人行迹、热点 IP 的真实地理、一个问题看懂（竖版拉新）。
> 选题依据：调研里已验证的需求（李白足迹 204 万、武王伐纣 166 万、“西天取经为什么绕远路” 198.6 万），加上地图适配度、文旅合作潜力、制作成本（能复用的瓦片区域）、合规风险。
> 每期史实都要在写稿时逐句核对一手史料；下文标“待核”的地方是写稿时必须确认的点，不能直接照抄进脚本。

## ep02 · 李白一生，到底走了多远？（10/16）

- **钩子**：他写尽了天下山水——一生到底走了多远？竖版：“李白的出生地，玄奘曾经路过”（碎叶城，与 ep01 联动）。
- **主线**：出生（碎叶说 / 蜀中说，两说并列，待核）→ 蜀中少年（江油、峨眉）→ 725 年“仗剑去国，辞亲远游”出蜀 → 江陵、洞庭、金陵、扬州 → 安陆十年 → 742 年待诏翰林“仰天大笑出门去”→ 744 年与杜甫相遇（洛阳、梁宋，待核）→ 齐鲁、江南漫游 → 安史之乱、入永王幕 → 流放夜郎，759 年白帝城遇赦“朝辞白帝彩云间”→ 762 年卒于当涂。
- **地图**：碎叶 → 四川 → 长江中下游 → 长安 → 山东 → 江南 → 夜郎方向（中途折返）→ 当涂。现有瓦片已覆盖全程；河流要补长江、汉水、淮河（`scripts/extract_rivers.py`）。
- **史实 × 文学**：每一站配一句李白自己的诗作为“戏”卡（诗句即一手材料）；路线长度用地图实测（地图上量出的近似值要注明“按路线估算”）。
- **竖版切片**：① 李白的出生地，玄奘曾路过 ② “朝辞白帝彩云间”，一天真能到江陵吗？（《荆州记》“朝发白帝，暮到江陵，其间千二百里”）③ 李白和杜甫一生见过几次？
- **文旅**：江油、马鞍山（当涂、采石矶）、宣城（敬亭山）、安陆、奉节（白帝城）、扬州。
- **史料**：《李太白全集》、李阳冰《草堂集序》、范传正《唐左拾遗翰林学士李公新墓碑》、詹锳《李白诗文系年》。
- **合规**：碎叶城在今吉尔吉斯斯坦境内，只画地形和古地名，不画国界。

## ep03 · 哪吒、姜子牙真的存在吗？封神之战的真实地图（10/23）

- **钩子**：封神榜里的大战，真实战场在哪？
- **主线**：周原、丰镐 → 孟津观兵 → 牧野之战（约前 1046 年）→ 朝歌。硬证据：利簋铭文“武王征商，唯甲子朝”（1976 年临潼出土，待核出土细节）。姜子牙（吕尚）是真实人物；哪吒形象源自佛教护法“那吒”，可追溯到印度神话（与 ep01 的印度段联动，待核源流）。
- **地图**：关中 → 豫北，小范围；加一条“那吒”从印度经西域传入中国的示意弧线。
- **竖版切片**：① 哪吒其实来自印度？ ② 牧野之战，只打了一个早上？ ③ 姜子牙钓鱼的地方在哪？（渭水磻溪，待核）
- **文旅**：宝鸡（周原、磻溪）、淇县（朝歌）、孟津、新乡（牧野）。
- **史料**：《史记·周本纪》《尚书·牧誓》、利簋铭文、《封神演义》。
- **合规**：不使用任何影视剧画面；神话人物用原创插画，考据式讲解，避免“魔改”。

## ep04 · 问汝平生功业：苏轼被贬了多远？（10/30）

- **钩子**：一生被贬三次，最远到了海南——苏轼一共走了多远？
- **主线**：眉山 → 1057 年进士 → 凤翔、杭州、密州、徐州、湖州 → 1079 年乌台诗案 → 黄州（《赤壁赋》）→ 回朝、再知杭州（苏堤）→ 1094 年惠州 → 1097 年儋州 → 北归，1101 年卒于常州。《自题金山画像》：“问汝平生功业，黄州惠州儋州。”
- **地图**：四川 → 中原 → 江南 → 岭南 → 海南（新增岭南、海南瓦片）。
- **竖版切片**：① 苏轼游的赤壁，根本不是三国那个赤壁（东坡赤壁 vs 赤壁市，为 ep08 预热）② “日啖荔枝三百颗”，苏轼在惠州 ③ 从惠州到儋州，路上走了多久？
- **文旅**：眉山、黄冈、惠州、儋州、杭州、常州——多城市，最适合做文旅合作样片。
- **史料**：《宋史·苏轼传》、孔凡礼《苏轼年谱》、苏轼诗文。

## ep05 · 被匈奴扣押十三年，他为什么还要往西走？（11/06）

- **钩子**：出发一百多人，回来只剩两个。
- **主线**：前 139 年出长安 → 河西被匈奴所俘，扣押十余年 → 逃脱西行，大宛 → 康居 → 大月氏 → 大夏 → 归途再被俘 → 前 126 年回到长安 → 第二次出使乌孙。“凿空”；“丝绸之路”一词由李希霍芬在 1877 年提出（待核年份）。
- **地图**：与 ep01 同一区域，**复用现有瓦片，制作成本最低**；可以把张骞与玄奘两条路线叠在同一张图上对比。
- **竖版切片**：① 出发一百多人，回来只剩两个 ② “丝绸之路”这个名字是德国人起的 ③ 张骞和玄奘，走的是同一条路吗？
- **文旅**：汉中城固（张骞墓）、敦煌、张掖、兰州。
- **史料**：《史记·大宛列传》《汉书·张骞传》。

## ep06 · 八百里梁山泊，为什么消失了？（11/13）

- **钩子**：《水浒传》里的八百里水泊，今天去哪了？
- **主线**：黄河决口使巨野泽扩大为梁山泊 → 北宋末宋江起事（《宋史》等记载的规模远小于小说，待核原文）→ 金元以后黄河改道南徙，水泊淤积 → 今东平湖为残留水面。用地图讲“黄河改道如何改写一部小说的地理”。
- **地图**：鲁西南、黄河下游；历史河道只能画“示意线”并在画面注明“示意”，来源要可追溯，不能照搬受版权保护的历史地图集。
- **竖版切片**：① 宋江起义，历史上有多少人？ ② 黄河改道，改写了一部《水浒传》 ③ 武松打虎的景阳冈在哪？
- **文旅**：梁山县、东平湖、阳谷、郓城。
- **史料**：《宋史》相关纪传、《水浒传》、黄河变迁研究论著（写稿时选定并注明）。

## ep07 · 六次东渡、双目失明，鉴真到底图什么？（11/20）

- **钩子**：第五次东渡，他竟然漂到了海南岛。
- **主线**：742 年日本僧人荣叡、普照到扬州邀请 → 五次失败（告发、海难，748 年漂到海南振州）→ 双目失明 → 753 年随遣唐使船第六次成功 → 萨摩登陆 → 奈良唐招提寺 → 763 年圆寂。
- **地图**：扬州 → 宁波 → 海南（第五次漂流）→ 日本九州 → 奈良；海路需要新瓦片。
- **竖版切片**：① 鉴真第五次东渡，漂到了海南 ② 唐招提寺的鉴真像，为什么闭着眼睛？ ③ 遣唐使的船有多危险？
- **文旅**：扬州（大明寺）、宁波、三亚。
- **史料**：真人元开《唐大和上东征传》。
- **合规**：东海海域只画航线和地名，不画任何边界线，不涉及岛屿主权话题。

## ep08 · 真实的赤壁之战，到底在哪？（11/27）

- **钩子**：草船借箭的，其实是孙权？
- **主线**：208 年曹操南下 → 荆州、长坂坡 → 孙刘联盟 → 赤壁（今湖北赤壁市一带为主流说法）→ 黄盖诈降火攻，《三国志》亦记疾疫 → 华容道撤退 → 三分天下。小说 vs 历史：草船借箭（《魏略》记孙权在濡须口，待核）、借东风、诸葛亮的戏份。
- **地图**：许昌 → 宛 → 襄阳 → 江陵 → 赤壁 → 乌林 → 华容。
- **竖版切片**：① 草船借箭的其实是孙权？ ② 曹操败走的华容道在哪？ ③ 赤壁之战，瘟疫比大火更致命？
- **文旅**：赤壁市、荆州、襄阳。
- **史料**：《三国志》（武帝纪、周瑜传、先主传）及裴注所引《江表传》《魏略》、《资治通鉴》。

## ep09 · 郑和下西洋，最远到了哪里？（12/04）

- **钩子**：郑和带回来的“麒麟”，其实是长颈鹿。
- **主线**：1405–1433 年七下西洋：太仓刘家港 → 占城 → 爪哇 → 满剌加 → 锡兰 → 古里 → 忽鲁谟斯 → 东非（麻林、木骨都束）；1414 年“麒麟”入贡（待核年份）。
- **地图**：印度洋、东非，需要新瓦片。
- **竖版切片**：① “麒麟”其实是长颈鹿 ② 郑和宝船到底有多大？（44 丈之说与学界争议并列）③ 郑和比哥伦布早了多少年？
- **文旅**：南京（宝船厂遗址）、太仓、泉州、长乐。
- **史料**：《明史·郑和传》、马欢《瀛涯胜览》、费信《星槎胜览》、《郑和航海图》。
- **合规（高）**：航线经过南海。镜头只跟随航线与港口，**不出现能被理解为中国全图的大范围画面**，不标注任何岛礁名称，不画边界。

## ep10 · 一个人走遍明朝：徐霞客的旅行地图（12/11）

- **钩子**：中国旅游日为什么是 5 月 19 日？（《徐霞客游记》首篇《游天台山日记》的日期）
- **主线**：江阴出发，三十余年遍游名山（天台、雁荡、黄山、武夷、庐山等）→ 1636 年“万里遐征”：浙、赣、湘、桂、黔、滇 → 丽江、腾冲、鸡足山 → 1640 年病归，次年卒。
- **地图**：东南 → 西南，新增云贵瓦片。
- **竖版切片**：① 中国旅游日为什么是 5 月 19 日？ ② 徐霞客发现了长江真正的源头？（《溯江纪源》中以金沙江为长江正源，待核篇名）③ 徐霞客最后一次出门，走了多远？
- **文旅**：江阴、天台、黄山、桂林、丽江、腾冲——文旅合作潜力最高的一期。
- **史料**：《徐霞客游记》。

## ep11 · 一骑红尘妃子笑：荔枝怎么运到长安？（12/18）

- **钩子**：荔枝三天就变味，唐朝人怎么送到长安？
- **主线**：杨贵妃嗜荔枝 → 产地两说（岭南 / 巴蜀涪州）→ 荔枝道（涪陵 → 达州 → 万源 → 西乡 → 子午道 → 长安）→ 唐代驿传速度 → 白居易《荔枝图序》“一日而色变，二日而香变，三日而味变，四五日外，色香味尽去矣”→ 用地图算一算能不能送到。
- **地图**：川渝 → 陕南 → 长安（荔枝道在 B站几乎没有像样的地图视频，是空白选题）。
- **竖版切片**：① 荔枝三天变味，唐朝人怎么保鲜？ ② 荔枝道到底有多长？ ③ 杨贵妃吃的荔枝，来自广东还是四川？
- **文旅**：涪陵、达州、万源、西乡、汉中。
- **史料**：白居易《荔枝图序》、《新唐书·杨贵妃传》、杜牧《过华清宫》、蔡襄《荔枝谱》。
- **版权**：只提及《长安的荔枝》小说/影视作为背景，不使用其任何画面。
